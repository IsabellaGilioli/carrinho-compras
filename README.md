# 🛒 Carrinho de Compras

Projeto simples de carrinho de compras desenvolvido com **JavaScript, HTML e CSS**.

## 💡 Funcionalidades

- Adicionar produtos ao carrinho
- Selecionar quantidade
- Cálculo automático do valor total
- Atualização dinâmica da interface
- Limpar carrinho com um clique

## 🧠 Como funciona

O sistema captura o produto selecionado, separa nome e valor unitário, calcula o subtotal com base na quantidade e atualiza o total geral em tempo real.

## 🛠️ Tecnologias usadas

- HTML5
- CSS3
- JavaScript (DOM manipulation)
